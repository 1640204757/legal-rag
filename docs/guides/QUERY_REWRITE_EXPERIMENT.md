# 口语改写：独立开发试验

## 本轮协议（2026-11-03，运行前固定）

目的：验证不依赖新增口语词表的查询改写，能否在保留事实的前提下改善检索。只测试查询表达，不改生产检索、不合并两路结果，不接入ChatService。

- 样本：将现有80道dev按题号排序，取索引`floor(i*80/20)`，共20道；不根据命中情况挑题，不读取holdout明细，不运行user10。
- 模型：当前Web配置的本机4B；沿用`OllamaClient.chat`的temperature=0、num_ctx=8192、num_predict=650、think=false。每题一次，无择优重试；超时60秒或格式错误回退原话，仍保留分母。temperature=0不保证跨环境完全复现。
- 提示：只要求忠实、清晰的问句，不给法名、条号、标准答案或目标正文。完整提示、哈希、模型摘要、语料指纹、数据哈希及源码哈希在调用前写入`protocol.json`。工作区未提交时明确记dirty，不能只用HEAD标识实验代码。
- 对照：同一进程、同一集合分别对原话和改写调用现有`measure()`；前4与前8独立执行，保留各路排名、候选ID、模式与错误。这里只比较替换查询后的结果，**不是保留原话再融合的线上效果**。
- 审核：JSON合法仅表示格式通过。逐条对照人物、关系、否定、时间、金额、不确定性和诉求；另存审核文件，不改模型原始输出。助手文本审核不是用户/法律专家复核，不足以成为论文最终金标准。
- 判据：任何事实改动都单独报告；必须同时列新增命中与丢失命中，不能仅报净增。此20题仅作开发筛选，不证明盲测泛化。若忠实性不可靠，不接入生产；若有可用收益，再独立设计融合，并跑全组测量/验收及全量测试。

## 入口与证据

使用`.local-python-path.txt`中的解释器：

```powershell
$projectPython = (Get-Content .local-python-path.txt -Raw).Trim()
& $projectPython -B -X utf8 scripts/experiment_query_rewrite.py --sample 20
```

输出位于`artifacts/local-rag/rewrite-runs/<时间>/`，不上传真实用户聊天。`protocol.json`冻结协议；`rewrites.json`保留送模消息、完整已返回的raw、候选问句、错误与耗时；`baseline.json`和`candidate.json`保存本批dev检索明细；`summary.json`是未经事实审核的分数，不能直接称为改进。中断时检查点保留，流式中断没有完整raw时不伪造输出。源码运行中改变或检索降级会退出非零。

阅读顺序：`select_dev → rewrite_once → run → measure → compare_records`；测试见`tests_local/test_rewrite_experiment.py`，覆盖dev隔离、无答案入提示、坏格式/异常回退、双向命中变化。生产的旧`local_rag/query_expansion.py`未修改、未接入。

## 第一轮真实结果：不采用（2026-11-03）

证据目录：[`20261103-215133-949419`](../../artifacts/local-rag/rewrite-runs/20261103-215133-949419/summary.json)。20题完整返回、格式全部通过、无检索降级、源码运行中未变。5题改写与原话完全相同，其余15题有文字变化。原话对照的前4/前8候选与上一轮正式测量对应20题完全一致，不是拿旧回答作基线。

| 指标 | 本批原话 | 未审核改写直接检索 |
| --- | --- | --- |
| 前4命中 | 11/20 | 9/20 |
| 前8命中 | 13/20 | 10/20 |
| 新增前4/前8命中 | — | 0 / 0 |
| 失去前4/前8命中 | — | 2 / 3 |

前4丢失D0702、D1207；前8另丢失D0804。D0702未触发词表，轻微文字整理后目标语义排名从9降至52；D0804从6降至11。因此退步不能全部归为扩展词表触发变化，当前向量结果也对表达变化敏感。

**事实审核与检索评分分开。** 在查看候选排名结果前，助手已对照20条原话/改写并写入[`factual-review.json`](../../artifacts/local-rag/rewrite-runs/20261103-215133-949419/factual-review.json)，发现3条明显语义变化：

- D0304：要求给付拖欠期间的额外款项，被改成允许继续拖延还款。
- D1103：对方编造“我没做过的事”，被改成“对方没有做过的事被编造”，主体关系改变。
- D1207：“把机关告了”，被改成“机关把他们告了”，诉讼双方关系改变。

另外17条仅标为“未发现明显变化”，并非事实正确性认证。此次审核者仍是助手，不是独立人工或法律专家；正式论文需要独立复核。尤其D0304、D1103尽管改错意思，检索仍然前4命中，说明命中率不能替代忠实性评价。不得把3/20当成总体错误率估计，也不得把另外17条称为经专业验证。

改写调用总耗时48.628秒，均值2.431秒、中位数2.185秒、最大7.659秒；包含模型状态检查及可能的首次加载。整个试验112.951秒。GPU占用未采集，这些是本机单轮观测，不代表跨环境性能承诺。

**证据保存。** `decision.json`记录不采用决定及关键原始报告哈希；另已核对执行源码哈希并将对应副本存入`source-snapshot/`，`environment.json`记录Python和主要依赖版本。原始输出未修改；已有工作区修改未提交，不能仅凭HEAD复现。本轮全量测试1056通过、14跳过、35个子测试通过，1条既有Starlette/httpx弃用警告，日志为该目录的`workspace-tests.log`。

**原因、识别、处理。** 本机小模型即使被要求“只整理文字”，仍可能改错主体和诉求；同时文字整理不必然更接近当前向量模型的表示。逐条对照原话与raw，加上同环境排名对照，才看出这两种问题。此次只保留实验工具与失败证据，不采用查询替换，也未测试候选融合；不能由此断言所有改写方法都无效。更换提示、模型或尝试融合都必须另立一次实验，不能把本轮结果包装成已解决口语泛化。

# 本地法律 RAG 使用说明

## 打开

先打开 Docker Desktop 并启动 `qdrant` 和 `legal-rag-qdrant-gateway`，再双击项目根目录 `start_local.cmd`，在浏览器访问 http://127.0.0.1:18765 。服务仅监听本机；不需要Colab、Kaggle、API密钥或模型微调。

本机模型：`qwen3:4b-instruct-2507-q4_K_M`（问答）和 `qwen3-embedding:0.6b`（向量）。4B是为了当前核显电脑的资源起点，未承诺律师级效果。以后可设置 `LOCAL_CHAT_MODEL=qwen3:8b` 切换已下载的本地模型，应用不自动下载也不转云端。不要同时运行多份服务，不支持多worker。

首次启动构建已入库资料的向量缓存，进度在右侧显示。构建期间可以使用关键词检索；缓存生成后写入 Qdrant，完成后切为 BM25 与 Qdrant 向量 RRF 混合检索。数据库不可用时显示关键词降级。查询不会写入向量缓存。向量缓存只存资料指纹及向量，不作为可公开发布数据。

## 使用

1. 描述事情和诉求，点击“开始分析”；Ctrl+Enter也可发送。
2. 助手可能追问，直接在同一会话补充。此前用户陈述和对话会用于下一轮检索/问答，模型说法不能当作证据。每轮用户原话与回答另存本地 `data/sessions/{会话编号}.jsonl`（明文，已加入 `.gitignore`）；被拦截、超时或出错也照记原始输出和原因。会话较长时，系统会只对**用户原话**做定向回查，把最多两条早期陈述以 `【前情陈述（第N轮用户原话）】：“……”` 注入本轮用户消息（单片 ≤200 字节、合计 ≤500 字节）；指代不清时不硬塞，改为在“## 追问”里澄清。删除某次会话的本地档案可调用 `ChatService.delete_archive(sid)` 或 `session_memory.delete_session_archive(sid)`。
3. 右侧“本次引用”由程序按模型声明编号附列原文；“检索候选”先列本轮检索的前8条，并标明哪些送入了模型；下面可展开“更多候选”，即关键词、语义两路各自前60名里没进前8的条文，未送入模型，仅供参考。说明见[展示候选](DISPLAY_CANDIDATES.md)。
4. 点击“展开原文”核对，或自主打开官方来源。咨询不自动访问外部来源。
5. “停止分析”传播取消并关闭下游读取，未完成答案不写入历史；不承诺引擎瞬间停算。“重新开始”清除服务会话、取消在途任务并换新会话。会话30分钟闲置过期，单次180秒超时。多轮不再按轮数硬拒绝：送模消息有 6800 字节目标线、7000 字节硬顶，超出时先压缩旧历史、再截断问题副本，法条材料始终至少保留一条完整条文（见[架构分层](ARCHITECTURE_LAYERS.md)）。

## 实际覆盖与局限

已保存22部规范（19部法律、2部行政法规、1部司法解释）、6个劳动案例发布稿摘要，共4019段。包括民法典、刑法、三大诉讼法、行政复议/处罚/许可/强制法、公司法、消费者权益保护法、劳动法及配套规范等。仅已登记条文范围；序言、附件尚未完整入库。现行性与版本适用未全面复核，不宣称覆盖全部法律。

核验只证明与已保存快照一致，未完成当前官方网页复核、版本适用、事实要件判断。检索相似也不等于支持结论。引用卡片不是“法定依据认证”。期限、主体、费用等重要结论需另行核对。

工资支付专项规定、刑诉法全文及大量司法解释等关键材料仍缺失，资料不足时应明确提示。自动混合检索是新增实现，效果仍需更大的独立评测集验证。模型可能错选材料或误解条件，系统不能仅凭编号检查保证内容正确。

数据均来自项目已有离线快照；本轮未重新采集法规、未上传任何真实案情。页面无CDN、外部字体及云模型入口。Ollama适配器仅允许环回地址，禁用环境代理和重定向，仅请求已安装的非cloud模型；本机引擎也应保持本地模式。软件自身不会自动调用远程模型。

## 数据与关闭

咨询仅在服务内存里；不写聊天文件或访问日志。浏览器页面内容在标签页关闭前仍可见。清空会话不等于物理擦除内存。进程重启后会话丢失。不要在咨询框中填写不必要的个人信息。

页面关闭不会自动停止服务。需要关闭服务时，在终端确认 data/runtime/server.pid 对应的是本项目 uvicorn 命令后再停止；Ollama是单独进程。再次双击启动脚本会复用已运行服务。

## 在另一台电脑安装

需要Windows Python 3.11+和官方Ollama。安装依赖：`python -m pip install --target .local-deps -r requirements-local.txt`。
下载模型：`ollama pull qwen3:4b-instruct-2507-q4_K_M` 与 `ollama pull qwen3-embedding:0.6b`。下载需联网，咨询过程只用本机服务。
`.local-python-path.txt` 是这台电脑的Python路径，不应公开；换电脑后设置环境变量 `LOCAL_RAG_PYTHON` 或使用系统Python。依赖、模型、原文/索引及真实咨询不能默认打包公开。

## 测试

本机没有可直接调用的 pytest 命令，使用 `python scripts/run_workspace_tests.py`（可带测试路径）；它把 `.local-deps` 加入 `sys.path`，并把会话冷归档隔离到本次临时目录（环境变量 `LEGAL_RAG_SESSION_DIR`），不会污染 `data/sessions`。当前全量结果：1136 通过、14 跳过、35 个子测试通过；会话底座专项见 `tests_local/test_session_memory.py` 和 `tests_local/test_dialogue_recall.py`。
真实模型和浏览器验证结果见 `artifacts/local-rag/` 与阶段交付报告；测试替身通过不能当作模型法律能力证明。

## 扩充资料与向量入库

运行 `python -m local_rag.ingest` 从源码登记的官方公开URL下载，原始HTML与条文保存在 `data/library/`。PARSED=条号连续性检查通过；QUARANTINED=正文不完整或未匹配，绝不进入检索。网页点击“加载新资料并入库”会重新读取磁盘资料并同步 Qdrant，无需重启网页服务。向量按模型指纹和条文哈希增量复用，并保存断点。

采集状态不代表法律效力。HTML、附件、案例再利用许可需分开核对，当前未授权这些数据用于训练或再分发。官方目录下载握手失败尚未取得，不称全量目录完成。

完整操作与容器分工见 [Qdrant 知识库与更新流程](QDRANT_KNOWLEDGE_PIPELINE.md)。Docker 关闭后不能执行向量入库；恢复后重新加载。

本批新增9部法律的采集结果见 [来源清单v3](../sources/source_catalog_v3.md)；[303项目录缺口](../sources/NATIONAL_LAW_COVERAGE_20260828.md)单列。资料范围继续优先扩充，案例、司法解释、行政及地方法规并未齐全。
